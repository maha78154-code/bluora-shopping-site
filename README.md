
# 💙 Bluora – Online Fashion Shopping Website

Bluora is a stylish and responsive online fashion shopping website built using HTML, CSS, and JavaScript. It showcases trendy clothing collections, including women's ethnic wear, kurtis, men's fashion, and western outfits.

The project aims to provide a simple, attractive, and user-friendly shopping experience with a modern fashion-store design.

## ✨ Features

- 🏠 Attractive homepage with a fashion hero banner
- 👗 Featured clothing categories
- 🛍️ Collections page navigation
- 🛒 Shopping cart interface
- 📦 Orders page navigation
- 👤 User registration page navigation
- ℹ️ About Us page
- 📱 Responsive layout for different screen sizes
- 🎨 Modern styling with CSS
- 🔗 Font Awesome icons for navigation

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive layout
- JavaScript – Interactive functionality
- Font Awesome – Icons
- Unsplash – Fashion images

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Bluora-Shopping-Website.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the Bluora fashion shopping homepage.
